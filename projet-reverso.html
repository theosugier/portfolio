Reverso

Application de chiffrement pour Windows qui cache un vrai message derrière une phrase anodine.

Contexte

Projet personnel. L'idée : chiffrer un message, puis le camoufler pour qu'il ressemble à un texte banal. Tout fonctionne en local, sans aucune connexion réseau, avec une clé USB comme clé physique.

Fonctionnalités

  • Chiffrement authentifié du message
  • Clé dérivée d'une phrase secrète ou d'une clé USB
  • Camouflage stéganographique : le message chiffré devient une phrase anodine
  • Coffre chiffré stocké en local
  • 100 % hors ligne

Mon rôle

  • Conception et développement complet, seul
  • Choix des algorithmes cryptographiques et de l'interface

Technologies

Python · CustomTkinter · ChaCha20-Poly1305 · Argon2id
