# Portfolio Théo Sugier

Mon portfolio pour le module HTML/CSS d'Ynov Aix, pour présenter mon parcours et mes projets.

Version en ligne : https://theosugier.github.io/portfolio/

## Lancer

Cloner le dépôt, puis ouvrir index.html dans un navigateur. Rien à installer.

git clone https://github.com/theosugier/portfolio.git

## Utiliser

Le menu en haut de chaque page mène à l'accueil, aux projets et au contact. Sur la page Projets, le bouton "Voir le projet" ouvre la page détaillée de chaque projet. Le CV se télécharge depuis la page Contact.
